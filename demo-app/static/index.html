This hub only simulates sign-up and invite links client-side (localStorage, this browser only) — it doesn't run the anonymous-invite backend from product-spec.html (shared access code validation, crypto-shredding). The intake and joint-session apps each show a banner with a "continue" link once the facilitator's own signal says the next step is ready, so you don't have to guess when to move on.
