Each step opens its own local prototype in a new tab. Facilitator replies use your real Anthropic key, so keep each app's own server running per its README.

    Invite the other person (optional)

  3. 3
    Joint session
    Whether you invited them or they invited you, this is where you both show up — each of you opens the session's own link with your own role, from separate devices or tabs.
    /joint/
  4. 4
    Post-session follow-up
    A private 1:1 afterward — handles any escalation disclosure first, then checks whether things actually got resolved.
    /post/
Sign-up checks a real access code and invites are real server-side records (crypto-shredded on accept/decline, per product-spec.html Section 3) — so an invite link works for a real second person on their own device, not just this same browser. Not built here: peer-suggested invites, invite expiry, or multi-org codes. The intake and joint-session apps each show a banner with a "continue" link once the facilitator's own signal says the next step is ready, so you don't have to guess when to move on.
