# Pitch Scripts by Audience

Same product, different language for different buyers. Each file is a ready-to-adapt script, not a finished email — swap in names, numbers, and specifics before sending anything.

**Tagline (use everywhere):** Heal the rift. Leave no trace.

| File | Audience | Use when |
|---|---|---|
| [investors-and-incubators.md](investors-and-incubators.md) | VCs, angels, accelerator partners | Pitch meetings, cold outreach to scouts/partners, demo-day style asks |
| [hr-people-ops.md](hr-people-ops.md) | HR directors, CPOs, HRBPs | Enterprise buyer conversations, pilot proposals |
| [warm-intro-mentors.md](warm-intro-mentors.md) | Alumni founders, mentors, scouts, judges | Getting a nomination or recommendation into a program, not a direct ask |
| [oss-maintainers.md](oss-maintainers.md) | Open-source maintainers / project leads | Tester recruiting and the OSS conflict-resolution use case |
| [legal-and-compliance.md](legal-and-compliance.md) | Employment counsel, compliance reviewers | Pre-pilot legal scoping, safety-floor stress-testing |
| [elevator-pitch.md](elevator-pitch.md) | Anyone, 30 seconds | Networking events, cold hallway conversations |
| [spouse-manager-referral.md](spouse-manager-referral.md) | Managers, personal network | Your wife's own referral email recruiting managers to test Seam |
