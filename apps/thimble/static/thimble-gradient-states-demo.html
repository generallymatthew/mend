E (Four-Color Bloom) keeps all 4 state colors -- idle-blue, listening-teal, thinking-honey, talking-pink -- anchored at fixed corners all the time; a state change only shifts each one's weight (46% active / 20% each neighbor / 14% opposite), which drives both its blob size and its share of the blended base fill. So thinking reads as mostly honey, but you can still see a pink patch, a teal patch, and a faint blue corner -- never a flat single color. D/A/B/C below use @property to register gradient positions/angle/color as typed custom properties so a plain CSS transition tweens them directly. The idle wobble (A/C) is a separate always-on @keyframes drift layered underneath. Needs a Chromium/Safari 16.4+/Firefox 128+ era browser for the smooth version; older engines still work but jump instead of glide.
