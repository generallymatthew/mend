How to run this (click to expand)
Serve the whole Mend/ folder: python3 -m http.server 8000, then open http://localhost:8000/launchpad.html — local document links need a real server, not file://. Local product links need ./run_all.sh running separately (repo root, needs caddy — see root README.md); it puts the core apps behind :8080. Every other page in the repo now carries a small "⌂ Launchpad" badge (bottom-right) back to this page — pages under apps/ point it at http://localhost:8000/launchpad.html since those are served by their own app server, not this one.
