## Non-dilutive compute/cloud credits

Apply to these in parallel — they directly remove the "paying $10–$15 out of pocket per test run" pressure.

| Program | Amount | Requirements | Status |
|---|---|---|---|
| Anthropic Startup Program | $1,000 Claude API credit + up to 1yr Claude Team (5 seats) | Bootstrapped/pre-seed, founded within 5 years, no funding required. Needs a custom-domain email (`founder@mend.work`), not Gmail. | Not yet applied |
| Google for Startups Cloud Program (Start tier) | $2,000 Cloud/Vertex AI credit | Pre-funded startup, custom domain | Not yet applied |
| AWS Activate Founders | $1,000 AWS credit | Self-serve, bootstrapped, apply via AWS Activate portal | Not yet applied |
| Microsoft for Startups Founders Hub | $1,000–$5,000 Azure credit | Lowest barrier to entry historically, no prior funding required | Not yet applied |

**Blocker before applying to any of these:** need a working `founder@` (or similar) address on `mend.work`. Cloudflare/registrar email *forwarding* is free and takes ~5 minutes to set up receiving; *sending* needs a free SMTP relay (Brevo or SMTP2Go free tier) wired into Gmail's "Send mail as." Neither is done yet as of this writing.
